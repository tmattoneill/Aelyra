Production Deployment Plan for Aelyra Multi-User Update

Pre-Deployment Analysis

Current State:
- Production is running at https://aelyra.moneill.net (working)
- Missing: SQLAlchemy, Alembic, and new multi-user database components
- Missing: Vite migration (migrated from Create React App to Vite)
- Environment configured for HTTPS production deployment

Prerequisites:
- Node.js 18+ required (for Vite compatibility)
- Check current Node.js version: node --version

Deployment Steps

1. Backup Current Production

# On production server
cd ~/Aelyra
cp -r . ../Aelyra-backup-$(date +%Y%m%d)
cp .env ../Aelyra-backup-$(date +%Y%m%d)/

2. Pull Latest Code

cd ~/Aelyra
git fetch origin
git checkout main
git pull origin main

3. Update Python Dependencies

source .venv/bin/activate
pip install -r requirements.txt
# This will install: SQLAlchemy 2.0.36, Alembic 1.14.0

4. Environment Configuration

Your current .env is mostly correct, but needs one addition:
# Add to existing .env:
DATABASE_URL=sqlite:///./aelyra.db

5. Database Setup & Migration

# Initialize database schema
alembic upgrade head

# Verify database was created
ls -la aelyra.db

6. Frontend Build & Deployment (Vite Migration)

cd frontend
npm install  # Update dependencies (includes Vite 6.x migration)
npm run build  # Now uses Vite instead of CRA (~800ms vs minutes)

# IMPORTANT: Build output is now in 'dist/' directory (not 'build/')
# Verify build completed:
ls -la dist/

# Copy dist files to your web server directory (not build files)
# Example: cp -r dist/* /var/www/html/

7. Service Restart

# Restart your production service (systemd/supervisor/pm2)
# Example if using systemd:
sudo systemctl restart aelyra

8. Verification Tests

- ✅ Check main app loads at https://aelyra.moneill.net (now Vite-powered)
- ✅ Test Spotify authentication flow
- ✅ Create a test playlist (will test database)
- ✅ Check Account Information tab works
- ✅ Verify Playlist History shows created playlist
- ✅ Test user profile customization (first name should persist after login)
- ✅ Verify faster load times (Vite vs CRA performance)
